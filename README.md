# FreeOSINT.org — Open Source Intelligence Training for Everyone

FreeOSINT.org is an open-source education platform for learning Open Source Intelligence (OSINT) through structured modules, practical exercises, curated resources, and responsible-use guidance.

The platform is designed for students, journalists, researchers, cybersecurity professionals, investigators, civic organizations, compliance teams, and anyone who needs to learn lawful, ethical, privacy-respecting OSINT methods.

## Mission

FreeOSINT.org exists to make OSINT education accessible without paywalls, advertising pressure, or opaque gatekeeping.

The project prioritizes:

- free public access;
- transparent development;
- community-contributed training material;
- ethical, lawful, and privacy-aware investigative practice;
- practical learning paths from beginner to advanced levels;
- responsible reporting and harm reduction;
- safe education without encouraging abuse.

## What This Repository Contains

This repository supports the FreeOSINT.org app and educational platform. It includes:

- project governance documents;
- contribution rules;
- responsible-use and ethics policies;
- security reporting instructions;
- privacy and data-handling notices;
- user, maintainer, and developer documentation;
- content authoring standards;
- legal and risk disclaimers;
- issue and pull request templates;
- release and documentation checklists.

## Platform Scope

FreeOSINT.org provides educational content and public-resource guidance.

It does not authorize users to access systems, accounts, datasets, devices, private communities, restricted networks, paid databases, leaked data, credentials, or private personal information.

Users are responsible for ensuring they have lawful authority for every investigation, research activity, verification activity, or security test they conduct.

## Core Learning Areas

The platform may include modules such as:

- introduction to OSINT;
- advanced search operators;
- source verification;
- social media intelligence;
- digital footprint analysis;
- geolocation and image verification;
- OSINT tools overview;
- cryptocurrency investigation fundamentals;
- dark web awareness and safety;
- public records research;
- reporting and documentation;
- operational security for researchers;
- ethical boundaries and privacy protection.

## Quick Start for Repository Maintainers

1. Review `RESPONSIBLE_USE.md`, `DISCLAIMER.md`, `SECURITY.md`, and `PRIVACY.md`.
2. Place learning modules under `content/modules/`.
3. Place curated tools and resources under `content/resources/`.
4. Place fictional or anonymized examples under `content/examples/`.
5. Use `.github/ISSUE_TEMPLATE/` for reports and content proposals.
6. Use `docs/content-authoring/module-template.md` for every new module.
7. Validate all contributions against `docs/governance/content-review-process.md`.
